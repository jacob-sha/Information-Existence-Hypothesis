# Terminology Note

The term **信息存在权** should be consistently translated as **Information Existence Right (IER)** throughout the IEH project.

Do not use alternative forms such as:

- Informational Existence Right
- Right of Information Existence
- Information Right to Exist
- Informational Right of Existence

The official terminology is:

```text
信息存在权 = Information Existence Right (IER)
```
