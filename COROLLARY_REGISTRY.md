# IEH Corollary Registry

This registry provides stable identifiers for all corollaries in the Information Existence Hypothesis (IEH).

Corollary numbers are **stable, append-only, and should not be renumbered** once assigned.

Logical reading order is maintained through `THEORY_MAP.md`, not through renumbering.

---

# 信息存在性假说推论登记表

本文件用于为 Information Existence Hypothesis（IEH）中的所有推论提供稳定编号。

推论编号一经分配，即保持稳定，原则上不重新编号、不插队、不复用。

理论阅读顺序通过 `THEORY_MAP.md` 维护，而不是通过重排推论编号维护。

---

## Numbering Policy / 编号规则

1. **Stable ID is the primary reference.**  
   Each corollary should be referenced by its stable ID, such as `C06-SPP`, `C12-GOV`, `C13-WAR`, or `C14-EDU`.

2. **Corollary numbers are append-only.**  
   New corollaries are added after the latest existing corollary number.

3. **Do not renumber existing corollaries after registry stabilization.**  
   Once this registry is adopted, existing corollary numbers should not be changed.

4. **Logical structure is maintained separately.**  
   The conceptual reading order of the theory is maintained in `THEORY_MAP.md`.

5. **Prediction records should use stable IDs.**  
   Prediction documents should reference corollaries through stable IDs instead of relying only on Roman numerals or Chinese ordinal names.

6. **Draft and placeholder corollaries protect theoretical priority.**  
   Draft or Placeholder status means the corollary records theoretical priority and structural position only. It should not be treated as a publication-ready essay.

## Stable ID Format / 稳定 ID 格式

Stable IDs follow this structure:

    C<number>-<short-code>

Examples:

    C06-SPP
    C07-ASI
    C12-GOV
    C13-WAR
    C14-EDU

Where:

- `C` means Corollary;
- the number is the stable corollary number;
- the short code identifies the concept.

## Status Definitions / 状态定义

| Status | Meaning |
|---|---|
| Active | Integrated into the main IEH structure and usable for theory mapping and prediction references. |
| Draft | Conceptually developed but still under refinement before full integration. |
| Placeholder | Structural position and theoretical priority are recorded, but the document should not be treated as a publication-ready essay. |
| Proposed | Candidate corollary not yet fully drafted or assigned. |
| Deprecated | Retained for historical reference but no longer used as an active theoretical component. |
| Superseded | Replaced or absorbed by another corollary, while keeping the original reference stable. |

## Cross-Reference Policy / 交叉引用规则

Prediction documents, evidence notes, and future essays should reference corollaries using stable IDs.

Recommended format:

    primary_corollaries:
      - C13-WAR
    supporting_corollaries:
      - C06-SPP
      - C12-GOV
    related_corollaries:
      - C07-ASI
    legacy_corollary_refs:
      - Corollary XIII

Older references such as “Corollary VI”, “推论六”, or “Super Prosperity Phase” remain valid as legacy references, but new documents should also include stable IDs.

## Public Draft Boundary / 公开草案边界

Draft and Placeholder corollaries should be treated as theoretical records, not as publication-ready essays.

They may include:

- title;
- core claim;
- concept definitions;
- relationship to other IEH corollaries;
- observable directions;
- falsifiability conditions;
- status notes.

They should avoid:

- complete media essays;
- polished narrative openings;
- full case-study development;
- final publication titles intended for external magazines;
- long passages that can be directly translated into submission articles;
- publication-ready argument flow.

中文说明：

Draft 或 Placeholder 状态的推论仅用于记录理论优先权、体系位置和核心机制，不应视为投稿成稿。

它们可以包含：

- 标题；
- 核心命题；
- 概念定义；
- 与其他 IEH 推论的关系；
- 可观测方向；
- 证伪条件；
- 状态说明。

它们应避免包含：

- 完整媒体文章；
- 高度打磨的叙事化开头；
- 完整案例展开；
- 面向外部期刊的最终标题；
- 可直接翻译成投稿稿的大段表达；
- 已经接近投稿成稿的完整论证线。
