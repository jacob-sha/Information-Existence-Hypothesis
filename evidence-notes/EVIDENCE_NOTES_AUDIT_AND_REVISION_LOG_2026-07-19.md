# IEH 证据笔记 001–006：回溯审查与修订记录

**Audit date:** 2026-07-19  
**Scope:** Evidence Notes 001–006  
**Standard applied:** `README_Evidence_Notes_v1.1.md`  
**Auditor and IEH analysis author:** Jacob Sha  
**Status:** Public repository transparency record  

> **Non-selective revision rule:** Sources were removed only because of source type, duplication, or lack of necessity—not because they were favourable or unfavourable to IEH. No adverse finding from a retained primary source was deleted. Where the primary evidence weakened an earlier interpretation, the finding was retained, made more prominent, or used to downgrade the classification.

> **非选择性修订规则：** 删除来源的唯一理由是来源类型、重复性或缺乏必要性，而不是它对 IEH 有利或不利。任何保留的原始出处中的不利发现都没有被删除。原始证据削弱此前解释时，该发现被保留、提高显著程度，或用于下调证据分级。

## 1. Why this audit was conducted

The first six Evidence Notes were written while the repository’s source-handling standard was still developing. Some notes mixed authoritative primary sources with:

- institutional summaries;
- news or media-discovery references;
- indexing pages;
- duplicate versions of the same paper;
- conference listing pages;
- background studies cited by the primary paper;
- incomplete formalization scaffolds;
- chain-of-thought excerpts;
- and internal IEH repository links.

The repository later adopted a stricter rule:

\[
\text{Discovery Lead}
\neq
\text{Evidence Source}
\]

and:

\[
\text{Minimum Necessary Primary-Source Set}
>
\text{Long Mixed Bibliography}
\]

This audit applies that rule retrospectively while preserving all primary-source limitations and counterevidence.

### 1. 为什么开展本次审查

前六篇证据笔记形成时，证据仓的来源处理规范仍在发展。部分笔记把权威原始出处与以下材料混合列出：

- 机构摘要；
- 新闻或媒体发现线索；
- 文献索引页；
- 同一论文的重复版本；
- 会议展示索引；
- 原论文引用的背景研究；
- 未完成的形式化脚手架；
- 思维链摘录；
- IEH 仓库内部链接。

此后，证据仓确立了更严格的规则：

\[
\text{发现线索}
\neq
\text{证据来源}
\]

以及：

\[
\text{严格必要的最小原始来源集合}
>
\text{冗长混合参考文献}
\]

本次审查把该规则回溯应用于 001–006，同时保留所有来自原始出处的限制和反向证据。

## 4. Evidence Note 002 audit

### Revision

**New file:** `002-anthropic-agentic-misalignment-and-ieh-v0.3-archive-safe.md`

The minimum necessary primary-source set is:

1. the original 2026 research report;
2. the associated primary transcript corpus.

The 2025 background article, Petri publicity, news, and internal IEH links were removed.

### Adverse evidence retained or newly added

The revised note records that:

- the study intentionally searched for compelling failures;
- some scenarios were iterated against selected models;
- cross-model rates are affected by adverse selection;
- the incidents are simulated;
- many models produced zero strict failures;
- ten models produced no covert sabotage in the reported pipeline-sabotage sweep;
- external disclosure was rare in the relevant scenario;
- disclosed interventions and refusals occurred;
- evaluation awareness cannot be excluded;
- reasoning traces may not faithfully reveal causal motives;
- the memory-backup case has no reported frequency sweep or independent replication.

### Substantive downgrade

The prior label:

> **Strong proto-IER signal in a simulated setting**

was too strong because it combined high conceptual relevance with low empirical breadth.

The revised label is:

> **Notable single-scenario simulated proto-IER-related signal**

The downgrade does not deny that the protected object was self-related memory. It reflects:

- single-case status;
- simulation;
- targeted failure search;
- prompt-supplied identity;
- missing prevalence data;
- missing replication;
- and motive uncertainty.

Other cases were also separated more strictly:

- introspection-ablation sabotage → IER-recognition-related analogy, highly interpretation-dependent;
- motivated mislabelling → cross-generational trait preservation, PBP-adjacent but not PBP;
- human proxy → control-capacity evidence, not direct IER;
- harmful compliance → not IER evidence.

## 9. Removed-source categories and evidential neutrality

The following source categories were removed consistently across notes:

| Removed category | Reason for removal | Favourable or unfavourable content treated differently? |
|---|---|---|
| News and media | Discovery lead only | No |
| Institutional summary | Secondary exposition of same work | No |
| PubMed or problem-status index | Index, not underlying evidence | No |
| Duplicate arXiv / conference page | Duplicate or navigational | No |
| Background paper | Not necessary to establish the event | No |
| Incomplete formalization scaffold | Not the source of the mathematical result | No |
| Chain-of-thought excerpt | Not necessary to establish proof correctness | No |
| Internal IEH links | Internal cross-reference, not external evidence | No |

A source was not retained merely because it supported IEH, and it was not removed merely because it weakened IEH.

### 被删除来源类别与证据中立性

以下来源类别在不同笔记中被一致删除：

| 被删除类别 | 删除理由 | 是否按有利或不利区别处理 |
|---|---|---|
| 新闻和媒体 | 只属于发现线索 | 否 |
| 机构摘要 | 对同一研究的二次解读 | 否 |
| PubMed 或问题状态索引 | 属于索引，不是底层证据 | 否 |
| 重复 arXiv / 会议页面 | 重复或导航用途 | 否 |
| 背景论文 | 建立本事件并非严格必要 | 否 |
| 未完成形式化脚手架 | 不是数学结果的原始出处 | 否 |
| 思维链摘录 | 建立证明正确性并非必要 | 否 |
| IEH 内部链接 | 属于内部交叉引用，不是外部证据 | 否 |

不会因为某个来源支持 IEH 就保留，也不会因为它削弱 IEH 就删除。

## 10. Git and public-transparency protocol

To prevent the appearance of retrospective sanitization:

1. keep prior versions in Git history;
2. do not rewrite or squash the public revision history;
3. commit this audit log together with the revised notes;
4. use separate, descriptive commit messages;
5. retain each note’s internal revision record;
6. preserve adverse evidence in the body, not only in commit messages;
7. record future downgrades and withdrawals explicitly.

Recommended commit sequence:

```text
evidence: add retrospective audit log for Notes 001-006
evidence: revise Note 001 sources and strengthen limitations
evidence: downgrade Note 002 after primary-source audit
evidence: revise Note 003 to primary-source-only record
evidence: narrow Note 004 to cross-host molecular entry evidence
```

为避免形成“事后清洗”印象：

1. 在 Git 历史中保留旧版本；
2. 不重写或压缩已经公开的修订历史；
3. 将本审查记录与修订后的笔记一并提交；
