# Changelog

## IEH v1.1 — Chapter Collection Structure

This version establishes the structured chapter-based edition of the Information Existence Hypothesis (IEH), based on the v1.0 baseline.

### Added

- Added Chinese chapter collection under `zh/`
- Added English chapter collection under `en/`
- Added chapter index for Chinese version: `zh/README.md`
- Added chapter index for English version: `en/README.md`
- Added cross-navigation among chapters
- Added figure links for each chapter
- Updated root README navigation to clarify full-text versions and chapter collections

### Structure

The repository now contains:

- `README.md` — Chinese full-text baseline
- `README_EN.md` — English full-text baseline
- `zh/` — Chinese chapter-based collection
- `en/` — English chapter-based collection
- `figures/` — official figure collection
- `glossary/` — terminology standard

### Purpose

The v1.1 structure is intended to improve:

- readability
- citation
- revision management
- bilingual maintenance
- long-term theoretical development
