# IEH Terminology Changelog

## v1.0

Initial official terminology standard for the Information Existence Hypothesis.

### Core decisions

- Standardized 信息存在权 as **Information Existence Right (IER)**.
- Standardized 人脑硅基化 as **Brain Siliconization (BS)**.
- Standardized 补丁式延续 as **Patch-Based Perpetuation (PBP)**.
- Standardized 人类信息生态位 as **Human Informational Ecological Niche (HIEN)**.
- Established the core conceptual chain:

```text
Information
        │
        ▼
Information Structure (IS)
        │
        ▼
Information Host (IH)
        │
        ▼
Information Existence (IE)
        │
        ▼
Information Existence Right (IER)
```
